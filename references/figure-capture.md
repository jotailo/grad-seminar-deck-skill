# 截原文图表：怎么截才叫「完整」

组会上被问「这图是你自己画的还是原文的」，答案必须是原文，而且**边缘一个字都没切**。
本文件的判据都写成了可执行的命令，不要靠眼睛估。

## 为什么必须从整页图裁，不能直接抽图

`--image-dir` 一类抽图功能按页面里的识别结果切块，**不保证**覆盖全部图表：图注常被当成正文单独切走，
坐标轴标签可能落在图外，表格会被切成若干条。用它当证据，迟早出现「表头缺一半」。
正确做法：整页渲染 → 按框裁 → 检测四条边。

## 步骤

`workbuddy-pdf` 技能目录一般是：
`<WorkBuddy 安装目录>/resources/app.asar.unpacked/resources/plugins/workbuddy-builtin/skills/workbuddy-pdf`
（找不到就用 `workbuddy-pdf` 技能自带的脚本路径；不确定时先 `ls` 一下再跑）。

```bash
# 1) 整页渲染，300dpi；双栏 + 小字（表格、图例）用 400
sh "<workbuddy-pdf 技能目录>/scripts/run.sh" "/abs/paper.pdf" "$WORK/pages" -f png --dpi 300
```
→ 每页一张 PNG。dpi 越高裁出来的图越清晰，但文件也越大；300 是够投影的底线。

```bash
# 2) 先定位：读正文拿到「图 N / 表 N ↔ 页码」
grep -n "Figure 2\|Table 1" "$WORK/content.md"
```
→ 得到每张图表在第几页，避免一页页翻。

```bash
# 3) 拿候选框（可选，但双栏页很好用）
python scripts/crop_figure.py --page pages/p05.png --propose
```
→ 按空白带切块，打印 `--bbox x0,y0,x1,y1` 候选行。这是**粗框**：跨栏大图会被切开，多子图（(a)(b)(c)）可能被分成两块，必须看图确认后再用。

```bash
# 4) 裁切（坐标是 0~1 相对比例，左上角为 0,0）
python scripts/crop_figure.py --page pages/p05.png --bbox 0.06,0.10,0.48,0.36 --out figs/paper1_fig1.png --pad 16
```
→ 输出图片，并**立即判定四条边有没有墨迹跨过边界**：
- `[OK] 四边无墨迹跨过边界，边缘完整` → 通过
- `[FAIL] 这些边的墨迹跨过了边界，内容被切开：{'bottom': 328}` → 按它给的建议坐标重跑，通常一次到位
- `建议坐标（已换算为相对比例）：bottom → 0.412` → 把 `y1` 换成 0.412 再来一次

```bash
# 5) 单张复查（也可以对别人给的图做体检）
python scripts/crop_figure.py --check figs/paper1_fig1.png
```
→ 报分辨率（按 8in 宽放置估算 dpi）、宽高比异常（>4:1 多半只截到一行）、边缘是否闭合。

```bash
# 6) 全部截完，拼一张审片图，一次看完
python scripts/contact_sheet.py figs/*.png -o figs/_sheet.png
```
→ 每格标注序号、文件名、像素、dpi；疑似裁断的格子会红框标 `EDGE`。低 dpi（<110）会标红。

## 什么算「完整」

| 元素 | 必须包含 | 常见切错 |
|---|---|---|
| 折线/柱状图 | 完整坐标框、两条轴的数字刻度、轴标题、图例、图注 | 左侧 y 轴数字被切；图注只截到「Figure」 |
| 表格 | 表头整行、所有列、表注（`Note:` / 显著性标记） | 最后一行被切；表头被当作正文单独切走 |
| 框架图 | 所有模块框、模块名、箭头、虚线框分组 | 右侧最后一个模块被切；跨栏图只截了半栏 |
| 多子图 | 若讲整体，必须含 `(a)(b)(c)` 全部；若讲局部，明确指一个子图并裁它的完整边框 | 切在子图中间 |
| 带公式的图 | 公式完整、上下标不丢 | 下标被切 |

判据只有一条：**四条边界的像素行/列上没有墨迹**。有墨迹 = 那个方向上还有内容被切断。

例外：满版图、无边框图、内容本身顶到版心边缘时，触边是正常的——此时必须**看图确认**再放过，并在 `caption` 里说明。

## 提高观感的四条

1. **裁松一点**：`--pad 16`（默认 14）。留白比贴边好看，也避免边缘字被切。
2. **宽高比接近版心**：单栏证据图 ~4:3～16:9 最服帖；太高的图（>1.4:1 竖向）会给文字留不下位置，考虑单独占一页（`image_only`）。
3. **dpi 够**：放到 8in 宽时有效 dpi ≥150 最佳，<110 会发虚（`check_deck.py` 会判 FAIL）。
4. **不要在 PPT 里拉伸**：`build_deck.py` 永远等比缩放并居中，不要手动改图片尺寸比例。

## 命名与图注

- 文件：`figs/<单元简称>_<fig|tab><编号>.png`，如 `figs/react_fig1.png`、`figs/memagent_tab2.png`。
- 图注：`图 1　一句话说明（原文 p.2 Figure 1）`——编号 + 说明 + 出处，三个都要。
- 自绘图标「自绘」：`图 1　三种设置的成功率（自绘，数据见实验记录 E-2401）`。**绝不把自己画的东西说成原文图**。
