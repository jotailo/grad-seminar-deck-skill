# 论文阅读汇报：逐页内容清单

一页 = 一个论点。每页 4–6 条要点，每条是判断句，不是名词短语。
下面的「必须写」缺一条就是没讲透，宁可少讲一篇论文，也不要把 4 页压成「结构复述」。

## 文献汇总表（多篇论文时，放在该种类第一位）

列固定四列、顺序不可调换，宽度建议 `[0.34, 0.22, 0.12, 0.32]`：

| 列 | 写法 | 反例 |
|---|---|---|
| 文献标题 | 照抄英文原题，不缩写、不自己译在前面 | 「ReAct 那篇」 |
| 出处 | 会议/期刊**缩写 + 年份 + 等级**，如 `ICLR 2023（CCF-A）` | 「某顶会」 |
| 发布时间 | 可核查的一个日期：arXiv 首次提交 `2022-10` 或正式发表 `2023-05` | 「去年」 |
| 一句话核心内容 | 动词开头的判断句，≤40 字，写「做了什么 + 发现了什么」 | 「研究了智能体」 |

- 行数必须等于论文篇数，顺序 = 讲述顺序。
- 单元格里不要出现括号套括号或「/」分隔的两个日期——表格列窄，会断成两行且断在难看的字符上。

## 第 1 页：标题 + 出处（`cards`，roles: `name`, `source`）

必须写：
- 英文原题（照抄）+ 中文译名（自己译，专有名词保留英文）
- 期刊/会议**全称 + 缩写**，不写「某期刊」
- **等级**，至少一条可核查口径：CCF 推荐类别（A/B/C）、中科院分区（大类/小类 + 是否 Top）、JCR 分区、或领域公认顶会
- 年份 + 卷期页 / arXiv 号 / DOI
- 第一作者与通讯作者单位
- 一句话定位：「它主张______，做法是______，在______上验证」

等级判定规则：
- 会议论文与期刊论文要分清，不要把会议论文写成「发表于某期刊」。
- 预印本必须标「预印本，未经同行评审」；它后来中了顶会就引正式版本。
- 两个口径结论不一致（如 CCF-B 但中科院一区）就都写，不要只挑好听的那个。
- 查不到就写「未核实（未在公开目录中检索到）」。这条比写错强一百倍。

## 第 2 页：观点 / 问题 / 论证（`image`，roles: `thesis`, `problem`, `argument`）

配图优先选：方法框架图（Figure 1/2）、机制示意图。图必须含图内的模块名与箭头标注。

必须写：
- **总观点一句话**（判断句）。反例：「本文提出了一种新方法，包括三个模块」——这是结构，不是观点。
- 支撑它的核心机制 2–4 条，每条「是什么 + 为什么重要」。
- 它反对谁、继承谁（与已有 1–2 条路线的关系）。
- **所解决的问题**：用作者的问题定义，别换成你的；具体痛点 2–3 条。
- **论证链**（最容易被跳过的一段）：现有方法在什么条件下失效 → 为什么会失效 → 作者的假设「若______则______」→ 由此必然导出、且能用实验观察到的现象 → 作者据此认为假设成立。

写论证链时把 5 行连成一条纵向链路，每行一句。听众要能看出「他的实验不是为了刷分，而是为了检验这个推论」。

## 第 3 页：实验设计与对应（`table`，roles: `experiment`, `mapping`, `contribution`）

表格四列，宽度建议 `[0.22, 0.26, 0.34, 0.18]`：

| 实验 | 设置 | 印证的观点 | 证据位置 |
|---|---|---|---|
| HotpotQA 多跳问答 | 与 CoT、Act-only 对比，同骨干模型 | 交替能减少推理链上的幻觉累积 | Table 1 / p.5 |

- 每一行必须能回答「这个实验**为了检验哪条观点**」；只能写「提升了性能」的行删掉。
- 消融实验要写清「删掉的是机制，不是模块」。
- `takeaway` 里写**贡献**（一句话，说清它给了后来者什么可复用的东西）。
- 页脚 `source` 写 `原文 p.5–8 表 1–4`。

## 第 4 页：个人观点（`bullets` 或 `image`，roles: `insight`）

四条以内，必须是「我」的判断，不是复述：
1. **可迁移的方法**：这篇的哪个做法我能直接用到自己的研究/实验里。
2. **可借鉴的实验设计**：它的哪个对照/消融我可以照做。
3. **可延伸的问题**：它没回答、但值得做的那一个。
4. **我认为的局限**：机制层面或实验覆盖上的具体缺口（不要写「样本量小」这种万金油）。

有空间就再配一张关键结果图（曲线/表格截图），并在 `caption` 里写清「图几　什么」。
`source` 写「个人判断，非原文结论」——让听众知道哪句该质疑。

## 常见扣分点（自查）

- 把「作者说了什么」讲完就结束，没有「实验如何证明」这一环。
- 对应表里出现「验证了方法的有效性」这种不能证伪的行。
- 讲了三篇论文，但汇总表只有两行；或汇总表顺序与实际讲述顺序不一致。
- 级别写「SCI 一区」却没说是中科院还是 JCR；或把 arXiv 预印本当正式发表。
- 个人观点写成「本文很有启发，值得学习」。
- 4 页里塞 5 张图，每张都看不清；正确做法是「1 图 + 1 表」讲透。
